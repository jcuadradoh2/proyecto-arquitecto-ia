# D-08 · Flutter para la app móvil

**Estado:** Propuesta (v1.0, 2026-09-25)  
**Sección del documento:** 7

## Contexto
Decisión tomada en el diseño de la arquitectura del Sistema de Banca por Internet de BP (modelo C4). El detalle completo, con el análisis de opciones y las consecuencias, se encuentra en la sección 7 del documento `Arquitectura_Banca_Internet_BP_C4.pdf`.

## Opciones evaluadas
- React Native
- nativo
- Kotlin Multiplatform

## Decisión
Flutter para la app móvil.

## Justificaciones
1. Rendimiento y consistencia con código AOT.
2. Ecosistema de seguridad (MASVS-R).
3. Menor costo y un ciclo de release.
